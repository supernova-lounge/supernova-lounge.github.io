# Supernova Lounge — меню

Онлайн-меню кальянной Supernova Lounge. Статичный сайт: `index.html`, `styles.css`, `app.js`.

**Как поменять позиции и цены:** откройте `menu.js` — там весь список. Каждая позиция записана как
`["Название", "Описание", цена]`. Сохраните файл — сайт обновится после публикации.
